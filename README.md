# API library service
API для управления библиотекой

## Описание
Сервис позволяет регистрировать пользоваьелей, заполнять сервис авторами, и книгами этих авторов, после чего пользователь может взять книгу для чтения, после того как он ее взял, другой пользователь не может найти эту книгу или же взять на чтение, пока первый не отдаст ее на сервис. Можно искать книги по автору, пользователю, и названтю книги, как же посмотреть список книг которые читает пользователь можно посмотрев самого пользователя. 


## 🚀 Стек
Python, DRF, PostgreSQL, Docker, Docker-compose

## Клонируйте репозиторий себе командой
```
git clone git@github.com:leonid-snp/Library.git
```

## Перейдите в проект командой
```
cd Library/
```

## Для работы переименуйте файл [.env.example](.env.example) в [.env](.env)
```
cp .env.example .env
```
## # django_setting
- SECRET_KEY= секретный ключ от приложения django
- DEBUG= режим отладки включен или выключен булево значение

## # bd_setting
- POSTGRES_DB= имя базы данных
- POSTGRES_USER= пользователь базы данных
- POSTGRES_PASSWORD= пароль от базы данных
- POSTGRES_HOST=db хост указан в файле [docker-compose.yml](docker-compose.yml) на строке №2
- POSTGRES_PORT= порт

## ▶️ Запуск
```
docker compose build
```
- затем

```
docker compose up
```
- можно одной командой

```
docker compose up -d --build
```
